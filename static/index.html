ABOUT · HONESTY PAGE

An audit, not a diagnosis.

What TimeLens does, how the agents are separated, and what it cannot claim.

The problem

Two named radiology error types motivate TimeLens (Kim–Mansfield classification): type 7, prior examination error — the current film is read without comparing to the prior — and type 12, satisfaction of report — undue trust in an earlier report repeats a wrong call. Every TimeLens case is a prior + current pair, and the image reader cannot access any report.

How a case is investigated

  1. Comparability gate (server code, before any model call): AP vs PA projection mismatch or byte-identical files stop the run with Cannot compare.
  2. Blind Reader agent in OpenSwarm calls read_pair: two independent Gemini reads with the films' slots swapped and chronology withheld. If the answers differ, the case is an Unstable read.
  3. Report Reader agent runs in parallel and calls read_reports: report text only; every supporting quotation is verified verbatim in code.
  4. Investigator agent, only when the stable blind read contradicts the report, calls reassess: one targeted, still report-blind second look, enforced once per run by the server.
  5. Plain Python assigns the status. A clinician approves, overrides (with a reason) or escalates; every action is logged.

Enforced boundaries

Each agent gets a fresh, per-run MCP connector exposing exactly one no-argument tool; cross-role calls are rejected by the MCP server. Image bytes and report text never enter OpenSwarm prompts — the tool sends them straight to Gemini and returns only structured findings. Connectors and modes are deleted when the agent finishes. The same tools also run headless (no agents) for the evaluation batch and as a fallback.

Data

NIH ChestX-ray14 (public, de-identified). Labels, views and follow-up order come from Data_Entry_2017_v2020.csv. Case E's current film is a cropped and brightened copy of the prior, a control for over-calling.

Limitations

  • Pleural effusion only; no severity, segmentation or other findings.
  • The pilot set is 19 pairs: it demonstrates behaviour, not accuracy (roughly ±20 points of uncertainty).
  • Gemini readings vary between runs; surfacing that variance is the point of the order-swap check.
  • No PACS, login or authenticated reviewer identity. Single-laptop local prototype.
  • OpenSwarm still exposes built-in tools at session level; the data boundary is enforced by keeping raw inputs inside the MCP tools.
